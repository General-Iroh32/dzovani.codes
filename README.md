# dzovani.codes — archived portfolio

[![Archived project](https://img.shields.io/badge/status-archived-6b7280)](https://general-iroh32.github.io/dzovani.codes/)
[![React](https://img.shields.io/badge/React-18-61DAFB?logo=react&logoColor=111827)](https://react.dev/)

This repository preserves the first generation of my personal portfolio. It was built with React, SCSS and Framer Motion and later received a dependency-maintenance pass. I am keeping it public as an honest snapshot of an earlier stage of my frontend work—not as the current source of truth for my projects or skills.

**[Open the archived site →](https://general-iroh32.github.io/dzovani.codes/)**

## What is preserved

- Responsive single-page portfolio layout
- Animated navigation and typewriter introduction
- Project and contact sections
- Reusable SCSS variables, mixins and component styles
- React error boundary and lazy-loaded sections

## Technology

- React 18
- JavaScript and SCSS
- Framer Motion
- CRACO / Create React App toolchain

## Run the archive locally

```bash
git clone https://github.com/General-Iroh32/dzovani.codes.git
cd dzovani.codes
npm install
npm start
```

Create a production build with `npm run build`.

## Maintenance status

The site is archived in spirit and will only receive narrowly scoped security or compatibility fixes. New portfolio work belongs in a clean, current implementation instead of continuously disguising this codebase as something newer than it is.
